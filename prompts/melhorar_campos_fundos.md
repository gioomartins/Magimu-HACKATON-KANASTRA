Melhore dois campos de restrições da Área dos fundos:
1. SITUACAO_CADASTRAL_SACADO:
    a. Use radio buttons para selecionar entre duas opções: "Ativa" ou "Inapta" (dentro do sistema, ambos campos devem ser formatados para uppercase).

2. TIPO_RECEBIVEL:
    b. Use checkbox para selecionar de 0 a 5 opções dentre:
        1. Duplicata
        2. Duplicata de Serviço
        3. Cheque
        4. CCB
        5. Nota Comercial
